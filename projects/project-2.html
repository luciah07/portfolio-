Social Network Analysis & Visualization



Overview

As part of my Leading People in Organizations course, I completed a project that applied social network analysis (SNA) concepts to organizational networks using Python. The objective was to move beyond manually interpreting network diagrams by developing a streamlined approach to modeling, analyzing, and ranking individuals based on their structural importance within a network.

The project implemented several network analysis techniques to evaluate individuals using metrics such as degree centrality, betweenness centrality, closeness centrality, eigenvector centrality, and overall network connectivity. By leveraging Python and graph analysis libraries, I automated the calculation of these metrics, enabling efficient comparison of different ranking methods across multiple social networks.

How it works

StepDescription
Import Network DataAn Excel spreadsheet containing individuals and their corresponding target connections (who each person is connected to) is imported into Google Colab using Python.
Construct the NetworkThe relationship data is converted into a graph, where each individual represents a node and each relationship represents a line connecting two nodes.
Calculate Network MetricsUsing pre-developed functions, the network is analyzed to compute several centrality measures that quantify each individual's importance within the network.
Rank IndividualsEach metric produces a ranking based on a different definition of influence, allowing the same network to be evaluated from multiple perspectives.
Visualize the ResultsThe network is displayed as a kite diagram. Nodes are color-coded according to their metric scores, making it easy to identify highly influential or well-connected individuals.

This project collects metrics for : Degree Centrality, Betweeness Centrality, Closeness Centrality, and Eigenvector Centrality.


For each centrality measure, the project generates a ranked list of individuals along with a corresponding network visualization. The color gradient applied to each node represents its relative score, allowing influential individuals and structural patterns within the organization to be identified quickly and compared across different ranking methods.

Results

Through this project, I've strengthened my understanding of how data-driven approaches can be used to analyze organizational structures, identify influential individuals, and uncover patterns in communication and collaboration networks. It also provided hands-on experience applying Python to solve real-world business analytics problems by combining organizational theory with computational analysis.
